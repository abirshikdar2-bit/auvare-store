# AUVARE — Curated Vintage & Pre-Loved Clothing

A luxury editorial vintage clothing storefront and owner/admin management dashboard built with pure HTML5, CSS3, JavaScript (ES6+), and Supabase Cloud.

## Features

### 🛍️ Public Storefront (`index.html`)
- **Luxury Editorial Aesthetic:** Warm off-white editorial theme (`#faf8f5`) with brand forest green accents (`#105036`).
- **Dynamic Category Navigation:** Smooth physics slider for category switches (All Drops, T-Shirts, Shirts & Polo, Jackets, Pants, Instagram Feed).
- **Service Guarantee Cards:** Fast delivery (1/2 Days), 100% Authorized Products, Customer Support (8am-10pm), Flexible Payment methods (bKash, Nagad, Cards).
- **Interactive Drops Catalog:** Real-time search, sizing badges (S, M, L, XL, XXL), product modal quick-view, and cart drawer.
- **Direct WhatsApp Ordering:** 1-click WhatsApp order routing with customer details and dynamic phone number synced from database settings.

### ⚙️ Owner & Admin Dashboard (`admin.html`)
- **Inventory Management:** Add, edit, restock, and archive clothing drops with multi-size inventory.
- **Order Tracking:** Real-time customer order processing, fulfillment status, and customer contact.
- **Team & Anti-Spam Security:** Super Admin access lock, role approvals, spam protection with permanent Block / Unblock controls.
- **Store Settings:** Live configurable WhatsApp, bKash, and Nagad numbers, hero banners, and Supabase cloud sync status.

## Tech Stack
- Frontend: Vanilla HTML5, CSS3, Modern JavaScript
- Backend & Database: Supabase Cloud (PostgreSQL, Supabase Auth, Storage)
- Deployment: Vercel Production
