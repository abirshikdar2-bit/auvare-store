# AUVARE — Curated Vintage & Pre-loved Clothing

A luxury digital storefront and full-featured cloud admin management dashboard for AUVARE clothing brand based in Bangladesh.

## Features
- **Curated 1-of-1 Catalog:** Live sizing (S, M, L, XL, XXL), instant condition grading, WhatsApp direct order dispatch.
- **Admin Management Portal:** Real-time inventory metrics, order tracking, team access controls with anti-spam blocking, and live Supabase cloud synchronization.
- **Unified Editorial Aesthetics:** Warm luxury off-white palette, fluid responsive layout, and zero-latency client-side rendering.

## Tech Stack
- Frontend: Vanilla HTML5, CSS3 Custom Properties, Modern JavaScript (ES6+)
- Database & Auth: Supabase Cloud (PostgreSQL, Realtime, OAuth Auth Gate)
- Hosting: Vercel Production
